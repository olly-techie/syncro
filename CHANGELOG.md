# Changelog

All notable changes to SYNCRO are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-09-12
### Added
- Initial V1 MVP: `syncro` CLI (detect → wireless ADB → scrcpy mirror).
- Options: `--list --device --quality --fps --fullscreen --dry-run --help --version`.
- Quality presets (low/balanced/high), FPS validation, known-device reconnect.
- User-local installer/uninstaller, POSIX sh libs, mock-based tests, docs.
